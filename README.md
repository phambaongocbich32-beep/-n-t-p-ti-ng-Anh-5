# Ôn Tiếng Anh 5 – Global Success (Học kỳ 1)

Web ôn tập Tiếng Anh lớp 5: từ vựng có tranh trong sách, mẫu câu, 13 trò chơi, đề ôn giữa kỳ và cuối kỳ, bài kiểm tra tự chấm điểm.

## Cách dùng
- Mở `index.html` bằng Chrome hoặc Edge (hoặc bật GitHub Pages: Settings → Pages → nhánh `main`, thư mục `/ (root)`).
- Giọng đọc nữ Anh Mỹ lấy từ trình duyệt. Có thể đổi ở nút **Giọng đọc**.

## Cấu trúc
- `index.html`: toàn bộ giao diện, mã và tranh (đã nhúng sẵn).
- `.nojekyll`: để GitHub Pages phục vụ tệp nguyên trạng.

Tranh minh họa lấy từ sách Tiếng Anh 5 – Global Success, tập một.
